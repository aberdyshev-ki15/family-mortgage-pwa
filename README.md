# Калькулятор семейной ипотеки — PWA

Откройте GitHub Pages по HTTPS в Safari на iPhone → «Поделиться» → «На экран Домой» → «Добавить».
После первого открытия дождитесь загрузки и запустите с иконки при наличии интернета, чтобы service worker закэшировал приложение.

Приложение работает автономно после первого успешного запуска. Расчёты выполняются локально, сервер для расчётов не требуется.

Исходный HTML калькулятора сохранён внутри index.html в сжатом виде. Внешние шрифты удалены для офлайн-работы. Правила расчёта перенесены из предоставленного исходника; их актуальность отдельно не проверялась.

Авторство исходного калькулятора сохранено в интерфейсе. Публикация осуществляется с разрешения правообладателя, подтверждённого владельцем репозитория в переписке.
